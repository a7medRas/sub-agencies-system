# 🎙️ نظام الوكالات الفرعية – Sub Agencies System

واجهة ويب (HTML/CSS/JS) لإدارة الوكالات الفرعية والمذيعين، بخط **Cairo** ودعم كامل للـRTL.  
النظام يعمل محليًا باستخدام **localStorage**، وجاهز للربط مع باك-إند مستقبليًا.

---

## ✨ المميزات
- 🔑 **نظام تسجيل دخول**:
  - مشرف عام (صلاحيات كاملة).
  - مدراء وكالات (إضافة/تعديل مذيعين + عرض الفواتير).
  - وكلاء (عرض فقط بدون تعديل).
- 🗂️ **إدارة الوكالات**:
  - بطاقة وكالة تحتوي (اسم – كود – الدولة – Likee ID – مسؤول الوكالة – عدد المذيعين – الفاصوليا – الفاتورة الشهرية).
  - بطاقات المذيعين مع جميع التفاصيل.
- 💰 **جدول رواتب عام (USD)**:
  - مدمج داخل النظام.
  - حساب تلقائي للراتب بناءً على الفاصوليا المحققة + الساعات/الأيام.
  - أمثلة:  
    - 4,500 فاصوليا + 30 ساعة ⇒ **37$**  
    - 300,000 فاصوليا + 30 ساعة ⇒ **1,760$**  
    - 1,200,000 فاصوليا + 30 ساعة ⇒ **6,400$**
- 📊 **تقارير وفواتير**:
  - عرض إجمالي الرواتب لكل وكالة.
  - تصدير البيانات إلى CSV/JSON (لاحقًا PDF).
- 🎨 **تصميم أنيق**:
  - خلفية خفيفة + Blur لنموذج تسجيل الدخول.
  - بطاقات منسقة بخط Cairo.
  - ألوان متناسقة (أبيض، رمادي، بنفسجي).

## 🚀 التشغيل محليًا
1. نزّل أو استنسخ المستودع:
   ```bash
   git clone https://github.com/<USERNAME>/sub-agencies-system.git
   ```
2. افتح الملف `index.html` مباشرة من المتصفح.

---

## 🌐 النشر على GitHub Pages
1. ادخل إلى Settings → Pages.  
2. من **Source** اختر:  
   - `Deploy from a branch`  
   - الفرع: `main`  
   - المجلد: `/ (root)`  
3. الرابط النهائي هيبقى:
   ```
   https://<USERNAME>.github.io/sub-agencies-system/
   ```
